## 🚀 Proyectos destacados

### 🟠 POS Baussa
> Sistema punto de venta de escritorio para comercios colombianos

Software completo en **PyQt6 + SQLite** con ventas, inventario, clientes con puntos de fidelidad, proveedores, compras, impresión térmica 80mm ESC/POS, facturas QR en línea, códigos de barras, cajón de dinero y cierre de turno. Empaquetado con PyInstaller.

[![Repo](https://img.shields.io/badge/Ver%20repo-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/sbaussa/pos-baussa)
[![Demo](https://img.shields.io/badge/Landing-000?style=flat-square&logo=vercel&logoColor=white)](https://sbaussa.github.io)

---

### 🍽️ Sistema POS Restaurantes — Baratón Suite
> POS web en tiempo real para dos restaurantes activos en producción

**Stack:** React + Vite · Node.js/Express · PostgreSQL · Railway + Vercel  
Órdenes por mesa / para llevar / domicilio, cocina en tiempo real con WebSockets, impresión térmica ESC/POS via agente Windows, pagos mixtos con QR, dashboard de ventas con filtros, reportes por hora y gestión de mesas con timers visuales.

---

### 🔧 Junior Technical Service (JTS)
> Plataforma de gestión para servicio técnico de electrónica

Sistema full stack con **React + Go + MySQL** (y variante Node.js). Libro de servicios, fotos por equipo, escáner de códigos de barras, impresión ESC/POS, landing pública con seguimiento de tickets, y despliegue en Railway + InfinityFree.

[![Landing](https://img.shields.io/badge/Landing-000?style=flat-square&logo=vercel&logoColor=white)](https://juniortechnicalservice.com)

---

### ✂️ BARBER v2.0
> App de escritorio para gestión de barbería

**PyQt6 + SQLite** — clientes, barberos, citas, cortes, caja registradora, dashboard con gráficas matplotlib, exportación a Excel, comisiones y horarios por barbero, y restricción de días de descanso en el agendador.
